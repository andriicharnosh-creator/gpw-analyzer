# 📈 GPW Analyzer — Feigin Capital

Aplikacja do analizy technicznej spółek z GPW i NewConnect.

## Funkcje
- RSI, MACD, Bollinger Bands dla wszystkich spółek
- Ranking z automatyczną punktacją sygnałów
- Wykresy świecowe interaktywne (Plotly)
- Analiza AI przez Claude Sonnet
- Alerty kupna/sprzedaży

## Uruchomienie lokalnie
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy na Railway
Podłącz repo do Railway — auto-deploy z Procfile.
